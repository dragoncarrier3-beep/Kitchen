# DoorCraft Configurator — Phase 1 POC

Interactive WebGL entrance-door configurator for the industrial manufacturing demo.

## Local

```bash
npm install
npm run dev
```

Open `http://localhost:5173`

## Deploy to Vercel

```bash
npx vercel
```

Or import the project in the Vercel dashboard. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

This POC uses a **Demo ERP Provider** only. It does not connect to live Priority ERP or SAP Business One.
